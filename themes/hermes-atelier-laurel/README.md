# Hermes Atelier

A second Hermes Desktop theme derived from the supplied reference image: warm vermilion, parchment cream, ink-brown linework, muted olive/gold accents, and a restrained hand-drawn laurel field.

## Install

Copy `plugin.js` to:

```text
$HERMES_HOME/desktop-plugins/hermes-atelier-laurel/plugin.js
```

Then reload desktop plugins and select **Hermes Atelier**.

## Visual language

- Vermilion/orange as the signature action color
- Parchment and cream surfaces instead of sterile white
- Ink-brown typography and borders
- Laurel line-art texture inspired by the reference illustration
- Subtle paper grain, not a noisy full-screen texture
- Serif editorial typography
- Slow movement only, with reduced-motion support
- Light and dark palettes are independently tuned

This remains a native theme plugin and does not modify Hermes Desktop source code.
