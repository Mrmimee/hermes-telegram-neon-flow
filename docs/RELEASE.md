# Release Guide

## Telegram Neon Flow 2.4.0

Telegram Neon Flow 2.4.0 is a Hermes Desktop-only theme release.

### Hermes Desktop

Install `plugin.js` under `$HERMES_HOME/desktop-plugins/hermes-telegram-neon-flow/plugin.js`, then select **Telegram Neon Flow** in the Hermes theme picker.

The Hermes edition provides Liquid Glass surfaces, aurora lighting, and independently animated floral doodles.

### Compatibility

The theme is implemented through Hermes Desktop's native desktop plugin system. Browser effects such as `backdrop-filter`, CSS animation and SVG backgrounds are provided by the Hermes plugin implementation.
