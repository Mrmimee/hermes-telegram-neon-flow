# Changelog

All notable changes to this project are documented here.

## [2.4.0] — 2026-09-16

### Hermes Desktop

- Consolidated the project as a Hermes Desktop-only theme.
- Preserved the Telegram Neon Flow Liquid Glass theme implementation.
- Preserved independent Light and Dark palettes, animated aurora, frosted surfaces and independently animated doodles.
- Removed obsolete cross-platform theme packaging and documentation.

## [2.3.0] — 2026-09-16

### Hermes Desktop

- Retained the existing Telegram Neon Flow Liquid Glass theme implementation.
- Preserved animated aurora, frosted surfaces and independently animated floral doodles.
